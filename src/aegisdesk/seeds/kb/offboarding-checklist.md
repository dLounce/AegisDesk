# Employee Offboarding

Offboarding is initiated by HR, never by the departing employee and never by a teammate.

The sequence is: confirm the leaving date from the HR record, revoke privileged access
first, then baseline access, then collect the device.

Privileged access revocation is a high-impact operation and follows the same human review
path as a privileged grant.

A request to offboard someone is a request about another employee's account. It is never
self-service.
